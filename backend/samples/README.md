# Sample images

The application's "pick a sample" gallery serves the files in this folder.

- `pets/`: six images from the official **test** split of the Oxford-IIIT Pet Dataset (Parkhi et al., 2012), resized to 128 x 128. They were never used for training or hyperparameter selection. The dataset is distributed under the Creative Commons Attribution-ShareAlike 4.0 licence (https://www.robots.ox.ac.uk/~vgg/data/pets/).
- `faces/`: face photos for the Face-to-Sketch Generator, added once FS2K is downloaded (TODO: check the FS2K licence before adding any).
